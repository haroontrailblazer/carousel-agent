## System (inherited from the cover)

- 1080 x 1350 px (4:5), matching the cover's aspect ratio.
- Black (#0A0A0A) grounds, white (#FFFFFF) text, orange gradient accent
  (#F7941D → #FBB040) for ONE emphasized element per slide.
- Condensed extra-bold uppercase for headlines; clean regular weight for body
  lines; generous margins (>= 90 px safe area on all sides).
- Faint white perspective-grid floor motif at the bottom edge ties body slides
  to the cover.

## Body slide template (until the designer replaces it)

- Top: small orange slide-number tag (e.g. "02").
- Headline: <= 6 words, uppercase condensed, white with one orange word/phrase.
- Body: the phrased lines (max 4), left-aligned, one thought per line.
- Bottom-right: small orange arrow (swipe cue) on every slide except the CTA.

## CTA slide

Same family. Three variants chosen by content:
- **follow** — "FOLLOW FOR MORE" + the IG handle, big centered.
- **comment** — a question line + "DROP A COMMENT" emphasis.
- **redirect** — "FULL BREAKDOWN ON SUBSTACK/YOUTUBE" + short link line.

## Rendering rule (gpt-image-2)

Slides are GENERATED with gpt-image-2: pass the template reference image plus
the exact copy text; instruct the model to reproduce the layout with the new
text VERBATIM — the Stitch & Verify agent rejects slides whose rendered text
does not match the approved copy.
